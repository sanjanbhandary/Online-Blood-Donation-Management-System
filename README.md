## Project Title
Online Blood Donation Management System

## Technologies Used
- HTML
- CSS
- PHP
- MySQL

## Features
- Donor Registration
- Blood Request Management
- Donor Database Storage
- User-Friendly Interface

## Purpose
The system helps connect blood donors and recipients by maintaining donor information and managing blood requests efficiently.
